# Проектная работа 3 спринта: Цифровая трансформация банка «Стандарт»

## Описание
В данном репозитории представлены артефакты, разработанные в рамках планирования цифровой трансформации банка «Стандарт». 
Цель проекта — спроектировать архитектуру и план перехода для запуска онлайн-каналов обслуживания (открытие депозитов и кредитов), чтобы привлечь новую аудиторию и повысить конкурентоспособность банка.

Работа выполнена в формате "Infrastructure as Code" и "Documentation as Code".

## Задание 2. Управление требованиями (FURPS+)

Цель задания — собрать, структурировать и приоритизировать требования к системе цифровой трансформации, учитывая функциональные потребности бизнеса и нефункциональные ограничения существующего ландшафта.

### Результаты
*   **Таблица требований FURPS+**
    Полный реестр требований, разбитый по категориям:
    *   **F (Functionality):** Основные сценарии для клиентов (онлайн-заявки) и сотрудников (обработка).
    *   **U (Usability):** Требования к единому дизайну, скорости отклика UI и поддержке через кол-центр.
    *   **R (Reliability):** Доступность 99.9%, защита АБС от перегрузки.
    *   **P (Performance):** Время отклика API < 200мс.
    *   **S (Supportability):** Использование существующего стека (Java, Oracle, .NET).
    *   **+ (Constraints):** Переход на микросервисы для новых функций, использование Kafka, шифрование.
