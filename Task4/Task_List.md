# Список задач для MVP "Открытие депозитов онлайн"

## Фаза 1: Фундамент (Месяцы 1-2)

### АБС (4 недели)
- T1.1: Проектирование АБС API Layer
- T1.2: Разработка REST endpoints (read-only)
- T1.3: Интеграция с Oracle БД
- T1.4: Тестирование и оптимизация производительности

### Rate Management Service (3 недели)
- T2.1: Проектирование модели данных
- T2.2: Разработка Rate Service (CRUD операций) на Java 21 + Spring Boot 3.4+
- T2.3: Разработка API для расчёта персональных ставок
- T2.4: Unit и интеграционные тесты

### Deposit Service (4 недели)
- T3.1: Проектирование модели данных заявок
- T3.2: Разработка Deposit Service (создание заявок) на Java 21 + Spring Boot 3.4+
- T3.3: Разработка бизнес-логики статусов
- T3.4: Интеграция с Rate Service
- T3.5: Unit и интеграционные тесты

### Инфраструктура (2 недели, параллельно)
- T4.1: Setup PostgreSQL кластера
- T4.2: Настройка API Gateway (Nginx/Kong)
- T4.3: Настройка CI/CD pipeline
- T4.4: Настройка мониторинга (Prometheus/Grafana)

### Сайт (3 недели, параллельно)
- T5.1: Дизайн формы подачи заявки
- T5.2: Разработка формы на React
- T5.3: Интеграция с Deposit Service API
- T5.4: Тестирование

## Критические зависимости:

```
АБС API Layer (T1) → Rate Service (T2) → Deposit Service (T3)
                        ↓
                      Frontend (T6), Админка (T7)
                        ↓
                   Интеграция КЦ (T10-T14)
```

## Примечания:

- Задачи в рамках одной фазы могут выполняться параллельно
- Критический путь: АБС → Rate Service → Deposit Service → Frontend
- Партнёрский КЦ не является блокером для MVP (можно запустить позже)
- Буфер 2 недели в Фазе 4 для непредвиденных проблем

## Технологический стек:

**Все новые микросервисы:**
- **Java 21 LTS** (сентябрь 2023) - стабильный LTS с поддержкой до 2029 года
- **Spring Boot 3.4+** - стабильная версия с полной поддержкой Java 21
- **PostgreSQL 15+** - для всех новых сервисов
- **Virtual threads** - включены для оптимизации производительности

**Обоснование выбора Java 21:**
- ✅ Зрелая версия с 2+ годами в production
- ✅ Virtual threads для high-concurrency приложений
- ✅ Поддержка до 2029 года (Oracle), до 2032 года (другие вендоры)
- ✅ Полная поддержка в Spring Boot 3.2+
- ✅ Единообразие стека для всех новых компонентов
