## Критический путь (Critical Path)

```
Месяц 1: АБС API Layer (4w)
    ↓
Месяц 1-2: Rate Service (3w) → Deposit Service (4w)
    ↓
Месяц 3: Frontend ИБ (4w) + Админка (3w)
    ↓
Месяц 5: Интеграционное тестирование (3w)
    ↓
Месяц 6: Пилот (2w) → Полный запуск (2w)

ИТОГО: 24 недели (6 месяцев)
```

## Риски и буферы времени

### Заложенные буферы:
- **2 недели** в Фазе 4 для исправления непредвиденных багов
- **1 неделя** в интеграции SFTP (на случай проблем с партнёром)
- **Параллелизация** задач для сокращения календарного времени

### Критические риски:
1. ⚠️ **Задержка АБС API Layer** → сдвигает всё на 1-2 недели
   - **Митигация:** Начать прямо сейчас, приоритет #1
2. ⚠️ **Проблемы с подрядчиком ИБ** (SMS-интеграция)
   - **Митигация:** Notification Service как альтернатива
3. ⚠️ **SFTP с партнёром не настроен**
   - **Митигация:** Партнёрский КЦ не блокирует MVP, можно запустить позже
