| Код    | Требования                                                                                                                                                                                                                     | Комментарий                                                                                                                                                  |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **F**  | **Функциональные (Functionality)**                                                                                                                                                                                             |                                                                                                                                                              |
| F1     | Клиент должен иметь возможность просмотреть список доступных депозитов с актуальными ставками на сайте и в интернет-банке.                                                                                                     |                                                                                                                                                              |
| F2     | Клиент должен иметь возможность подать заявку на открытие депозита через сайт (указав ФИО и номер телефона) или через интернет-банк (указав счет и сумму депозита с подтверждением через СМС-код).                             |                                                                                                                                                              |
| F3     | Клиент в интернет-банке должен видеть персонализированные ставки по депозитам для своего профиля.                                                                                                                              |                                                                                                                                                              |
| F4     | Система должна автоматически отправлять СМС-уведомления клиенту на ключевых этапах обработки заявки (подтверждение операции, подтверждение ставки, открытие депозита/кредита, изменение статуса заявки).                       |                                                                                                                                                              |
| F5     | Клиент должен иметь возможность подать заявку на кредит через сайт (с указанием ФИО, телефона и опционально паспортных данных) и через интернет-банк с подтверждением через СМС-код.                                           |                                                                                                                                                              |
| F6     | Система должна предоставлять клиентам предодобренные кредитные предложения в интернет-банке на основе предварительного скоринга.                                                                                               |                                                                                                                                                              |
| F7     | Система должна автоматически выполнять кредитный скоринг при подаче заявки на кредит (используя данные БКИ для новых клиентов и внутренние данные АБС для существующих).                                                       |                                                                                                                                                              |
| F8     | Сотрудники бэк-офиса депозитов должны иметь возможность обрабатывать онлайн-заявки на депозиты в АБС с подтверждением условий (для MVP).                                                                                       | MVP предполагает ручную обработку заявок на депозиты сотрудниками бэк-офиса. Полная автоматизация - цель на год.                                             |
| **U**  | **Удобство использования (Usability)**                                                                                                                                                                                         |                                                                                                                                                              |
| U1     | Все интерфейсы интернет-банка и сайта должны соответствовать единой системе дизайна компании с использованием привычных для клиентов цветов и брендированных элементов.                                                        |                                                                                                                                                              |
| U2     | Интерфейсы подачи заявок должны быть максимально простыми и понятными для основной аудитории банка (люди старшего возраста), с минимальным количеством шагов и понятными подсказками.                                          |                                                                                                                                                              |
| U3     | Отклик пользовательского интерфейса на действия клиента должен быть максимально быстрым (загрузка справочных данных и форм должна занимать менее 1 секунды вместо текущих >1 сек).                                             |                                                                                                                                                              |
| U4     | Система должна предоставлять альтернативный канал обслуживания через кол-центр для клиентов, испытывающих сложности с использованием онлайн-каналов.                                                                           |                                                                                                                                                              |
| U5     | Сотрудники кол-центра (включая партнёрский) должны иметь доступ к актуальным ставкам по депозитам для консультирования клиентов.                                                                                               | Учитывая возрастную аудиторию и планируемую маркетинговую кампанию, критично обеспечить простоту использования и поддержку через кол-центр.                  |
| **R**  | **Надёжность (Reliability)**                                                                                                                                                                                                   |                                                                                                                                                              |
| R1     | Все онлайн-сервисы (интернет-банк, сайт, новые микросервисы) должны обеспечивать доступность 99,9% (24/7), что допускает не более ~8,76 часов простоя в год.                                                                   |                                                                                                                                                              |
| R2     | Интернет-банк должен поддерживать автоматическое переключение на резервный ЦОД в случае сбоя основного ЦОД без потери доступности для клиентов.                                                                                |                                                                                                                                                              |
| R3     | Новые компоненты системы НЕ должны создавать критическую нагрузку на БД АБС (Oracle), которая уже находится под высокой нагрузкой. Необходимо избегать прямых API-вызовов из интернет-банка к АБС в процессе обработки заявок. |                                                                                                                                                              |
| R4     | Система должна защищать критически важные компоненты (система кредитного скоринга) от избыточной нагрузки, особенно в рабочие часы. Предрасчёты скорингов не должны создавать дополнительную нагрузку на скоринговую систему.  |                                                                                                                                                              |
| R5     | Архитектура новых компонентов должна поддерживать горизонтальное масштабирование для обработки растущей нагрузки от онлайн-заявок (аналогично Кредитному конвейеру и системе скоринга).                                        |                                                                                                                                                              |
| R6     | Система должна обеспечивать отказоустойчивость критических операций (подтверждение заявок, отправка СМС, фиксация ставок) с возможностью восстановления при сбоях.                                                             | АБС масштабируется только вертикально из-за архитектуры Oracle БД, что делает защиту от перегрузки критически важной.                                        |
| **P**  | **Производительность (Performance)**                                                                                                                                                                                           |                                                                                                                                                              |
| P1     | API новых компонентов системы должны обеспечивать время отклика не более 100-200 миллисекунд для операций просмотра данных (список депозитов, ставки, статусы заявок).                                                         |                                                                                                                                                              |
| P2     | Система должна обеспечивать равномерное распределение нагрузки между серверами приложений и ЦОД для предотвращения перегрузки отдельных узлов.                                                                                 |                                                                                                                                                              |
| P3     | Заявки на кредит с предодобренными предложениями должны обрабатываться сотрудниками в течение одного рабочего дня (вместо текущей недели).                                                                                     |                                                                                                                                                              |
| P4     | Новые компоненты должны поддерживать горизонтальное масштабирование для обработки растущего количества онлайн-заявок без деградации производительности.                                                                        |                                                                                                                                                              |
| P5     | Справочные данные (список депозитов, ставки) должны загружаться менее чем за 1 секунду (исправление текущей проблемы с загрузкой >1 сек).                                                                                      |                                                                                                                                                              |
| **S**  | **Поддерживаемость (Supportability)**                                                                                                                                                                                          |                                                                                                                                                              |
| S1     | При доработках необходимо максимально использовать существующие в банке технологии: Oracle, MS SQL, Java, .NET, Python, чтобы минимизировать потребность в новой экспертизе.                                                   |                                                                                                                                                              |
| S2     | Новые технологии должны быть совместимы с существующими платформами разработки и языками программирования, которыми владеют сотрудники IT-отдела банка.                                                                        |                                                                                                                                                              |
| S3     | Архитектура новых компонентов должна предусматривать возможность для расширения функциональности командой банка без критической зависимости от подрядчиков.                                                                    |                                                                                                                                                              |
| S4     | Необходимо разработать техническую документацию для всех новых компонентов и интеграций для обеспечения дальнейшего развития системы.                                                                                          |                                                                                                                                                              |
| S5     | Изменения в ядре интернет-банка, требующие участия подрядчика (например, работа с СМС), должны быть минимизированы. Новый функционал реализуется силами команды банка.                                                         | В команде АБС есть специалисты с Java-экспертизой, что позволяет самостоятельно дорабатывать системы на этом стеке (Кредитный конвейер, система кол-центра). |
| **+R** | **+ Ограничения (Restrictions)**                                                                                                                                                                                               |                                                                                                                                                              |
| +R1    | Для организации асинхронного обмена данными использовать Apache Kafka как стандарт для очередей сообщений на перспективу.                                                                                                      |                                                                                                                                                              |
| +R2    | Текущая платформа интернет-банка (ASP.NET MVC 4.5 / .NET Framework 4.5) несовместима с Kafka. Рассмотреть переход на микросервисную архитектуру для новых функций (начиная с открытия депозитов).                              |                                                                                                                                                              |
| +R3    | Все данные, передаваемые между клиентом и банковскими системами (сайт, интернет-банк), должны быть защищены механизмом шифрования трафика (HTTPS/TLS).                                                                         |                                                                                                                                                              |
| +R4    | Новые клиенты банка должны проходить обязательную личную идентификацию в отделении в соответствии с требованиями ЦБ РФ (для депозитов и кредитов, оформленных через сайт).                                                     |                                                                                                                                                              |
| +R5    | Запрещено создавать прямые интеграции онлайн-каналов с БД АБС (Oracle) для избежания критической перегрузки. Интеграции должны быть реализованы через промежуточные слои/очереди.                                              |                                                                                                                                                              |
| +R6    | Партнёрский кол-центр может получать данные только в виде файлов (например, через SFTP), API-интеграции с внешней системой недоступны.                                                                                         |                                                                                                                                                              |
| +R7    | В качестве СУБД для новых компонентов использовать Oracle или MS SQL для соответствия существующей инфраструктуре (допускается PostgreSQL для микросервисов по аналогии с системой кол-центра).                                | Ограничения связаны с существующей инфраструктурой, требованиями безопасности и регуляторными нормами.                                                       |
